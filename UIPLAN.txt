    Explanation of Key Directories
  
     * `src/assets`: Global static assets like images, fonts, and global CSS files (if any).
  
     * `src/components`: This is for reusable, generic components that are not tied to any specific feature.
         * `common/`: Basic building blocks of your UI (e.g., a customized Button that is used everywhere).
         * `layout/`: Components that define the main structure of the app, like the Sidebar and Header, which wrap the page content.
  
     * `src/features`: The core of the application. Each sub-directory is a self-contained feature. This makes the codebase easy to navigate and maintain. A typical feature folder contains:
         * `*.Page.tsx`: The top-level component for a specific route (e.g., WorkflowsListPage.tsx). It assembles other components to create a full page.
         * `api.ts`: Functions for making API calls related to this feature (e.g., getWorkflows, createWorkflow).
         * `components/`: Components that are specific to this feature and not used elsewhere (e.g., WorkflowCanvas is only used within the "workflows" feature).
         * `hooks/`: Custom React hooks with logic specific to the feature (e.g., useWorkflowBuilder would contain the complex state management for the builder canvas).
         * `types.ts`: TypeScript types and interfaces for the feature's data structures.
  
     * `src/hooks`: For global, reusable hooks that can be used across multiple features (e.g., useLocalStorage).
  
     * `src/lib`: For third-party library setup and configuration.
         * `axios.ts`: A pre-configured Axios instance. This is where you'd set the base API URL and create interceptors to automatically attach the JWT authentication token to every request.
  
     * `src/providers`: For wrapping the application with global context providers. The AppProvider.tsx would contain the React Router, state management store provider (e.g., Redux), and the MUI theme provider, keeping App.tsx clean.
  
     * `src/routes`: Defines the application's URL routes.
         * `index.tsx`: Maps URL paths to their corresponding page components.
         * `ProtectedRoute.tsx`: A special component that checks if a user is authenticated before rendering a page. If not, it redirects them to the login page.
  
     * `src/store`: For global state management using a library like Zustand or Redux Toolkit. It defines the main store and combines the "slices" or reducers from different features.
  
     * `App.tsx`: The root component of the application. It typically renders the main router and providers.
  
     * `main.tsx`: The entry point of the application, where the root App component is rendered into the DOM.
