Ports & routing

Traefik is the only container with host ports. It routes by host name and path to containers on the edge network, and to the engine through an internal entrypoint that is never published. Everything else listens only inside Docker networks or on the VM loopback.

VM paths

Where things live on the VM. The checkout path comes from the DEPLOY_PATH secret; the box above changes it everywhere on this page. Named volumes are prefixed with the Compose project name wbskt_.

Runbook

Copy-ready commands. Unless a card says otherwise, run them on the VM from /deploy/compose, where Compose finds docker-compose.yml and .env. Commands that read a secret read it inside the container, so nothing secret is typed or echoed.

Release pipeline

Two repos, two release streams, one VM. CI builds every image; the VM only pulls. There is no inbound deploy endpoint: a workflow SSHes in with a key pinned to deploy.sh.

Observability

Every host sends traces, metrics and logs over OTLP to the collector, which fans them out. None of it is publicly routed: open Grafana through an SSH tunnel.
